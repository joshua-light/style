What a cow costs

How well do Claude models handle a large coding task, and what does it cost? We start with the simplest approach and add one thing at a time.

The task

Add a cow to a Minecraft clone written in Rust. The game has no animals yet, so the cow is the first.

AgentClaude Code, one model
GameMinecraft clone, no animals
CowBuilt by the agent
43 checksRun in the real game
Checks 43
  • Looks and moves · Its model, texture and size; it walks, swims and avoids edges (13)
  • Combat · It takes damage, flees and dies (6)
  • Drops · Beef and leather; cooked beef if it burns (5)
  • Interaction · Milking, feeding, breeding, calves (13)
  • Following · It follows a player holding wheat (5)
  • Spawning · Cows appear in the world (1)

Every approach below gets two numbers: checks passed, out of 43, and cost, the API bill for the whole run. Each approach ran once per model.

More iterations

What if someone plays with Haiku's cow and reports what is wrong? Six bugs went back to it:

  • It walks off high edges.
  • It flees only on grass.
  • It drops raw beef when it dies burning.
  • It won't breed while you hold wheat.
  • It can't walk around a wall to follow you.

Harness

What if the agent can check its own work while it builds? It gets the spec and a verify command, which runs all 43 checks and prints pass or fail. Together they are the harness.

Prompt + specWhat a cow is and does
AgentBuilds, then runs verify
Verify43 checks, pass or fail
CowDone when all pass

Every Sonnet and Opus run passed all 43. Sonnet low did it for $3.49, a fifth of Opus alone.

Note

Verify runs the same checks that score the cow. The agent was coached toward the test, so these scores lean optimistic.

Problem: who builds the harness?

The harness made the cheap run possible. But someone had to write the spec and the 43 checks. Here that was done by hand, outside the runs, so its cost is in none of the numbers above.

To beat Opus alone, building the harness must cost less than $15.79.

So the real question: can a smarter model build the harness cheaply? A cheaper model then builds the feature with it. Together they must cost less than the smart model alone.

Appendix: navigation

Before it writes any code, every agent has to find its way around the codebase. That reading is one of the biggest costs in a run. Seven aids tried to cut it, each on one Sonnet medium run.

Gray is the run with no aid. Hover a row to see what the aid was.

Most aids cut the reading cost. None cut the whole run: totals stayed within the normal $1.67 spread between runs, and the 1M window cost more.
